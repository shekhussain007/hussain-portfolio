# Hussain Portfolio — starter website

A responsive, single-page video editor portfolio inspired by the reference screenshots.

## Run it
1. Extract this ZIP.
2. Open the `hussain-portfolio` folder in VS Code.
3. Open `index.html` in your browser. For a smoother development experience, use the VS Code Live Server extension.

No build step or paid software is required.

## Before publishing, replace these placeholders
- `HUSSAIN` with your preferred display name if needed.
- `YOUR_EMAIL@example.com` in `index.html`.
- `YOUR_INSTAGRAM` in `index.html`.
- Replace the sample Unsplash image URLs with thumbnails or video previews from your own projects.
- Replace the sample project titles/descriptions with real work. Do not present sample imagery as client work.

## Publish
This is a static site and can be deployed to Cloudflare Pages or another static host. Upload the folder or connect its GitHub repository. A custom domain is optional.

## Notes
The page uses Google Fonts and Unsplash images, so those visual assets require an internet connection. The website code itself is free to edit and use.
